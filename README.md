# Academia MM

Área interna de treinamento comercial da **MM Suplementos**.

Esta primeira versão apresenta o treinamento **Atendimento Consultivo — V1.3**. O arquivo `index.html` é a página principal, baseada no HTML original fornecido pela MM.

## Publicação

GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.
O arquivo `.nojekyll` permite servir os arquivos estáticos diretamente, sem processamento pelo Jekyll. Não há dependências, instalação ou etapa de compilação.

O público-alvo é a equipe MM, mas esta hospedagem é pública e não possui autenticação.

## Organização e próximos treinamentos

- `index.html`: treinamento atual e página de entrada da primeira versão.
- `treinamentos/`: reservado para futuros treinamentos, cada um em sua própria pasta.
- `assets/`: reservado para imagens, estilos e scripts compartilhados.
- `docs/`: orientações de manutenção e expansão.

Consulte [a estrutura de expansão](docs/ESTRUTURA.md) antes de acrescentar um treinamento. Textos, preços, produtos, estratégias, perguntas e respostas comerciais só devem ser alterados com validação da MM.

## Verificação antes de publicar alterações

Confira todos os módulos, botões, impressão, quiz incompleto e completo, sorteio e revelação das simulações. Teste telas de computador e celular, incluindo tabelas largas e rolagem. Confira também o console do navegador.
